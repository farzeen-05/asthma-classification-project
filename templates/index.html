Project Methodology

Step-by-step process followed in building the Asthma Classification System

  • Data Collection
  • Data Preprocessing
  • Feature Selection
  • Model Training
  • Evaluation & Prediction

Data Collection

Gathering relevant patient data for analysis

The dataset includes patient information such as age, symptoms, smoking habits, allergies, and breathing difficulties. This data is essential for training machine learning models.

Data Preprocessing

Cleaning and preparing data for better performance

Missing values are handled, categorical variables are encoded, and data is normalized to improve the efficiency and accuracy of the model.

Feature Selection

Selecting important features for prediction

Important health parameters are identified to reduce complexity and improve model performance.

Model Training

Training machine learning algorithms

Multiple models such as Logistic Regression, Decision Tree, Random Forest, SVM, and KNN are trained and compared to select the best-performing model.

Evaluation & Prediction

Testing and generating predictions

The model is evaluated using accuracy and other metrics. Once validated, it is used to predict asthma severity based on new patient input.
