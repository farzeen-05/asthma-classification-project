Asthma Classification Project

Comprehensive explanation of dataset, models, and results

📊 Dataset

The dataset contains patient information such as age, symptoms, smoking habits, allergies, and breathing difficulties used for asthma classification.

⚙️ Algorithms Used

Logistic Regression, Decision Tree, Random Forest, Support Vector Machine (SVM), and K-Nearest Neighbors (KNN) are used to train and compare model performance.

📈 Model Performance

The models are evaluated using accuracy, precision, recall, and confusion matrix to determine the best-performing algorithm.

🎯 Final Output

The system predicts asthma severity levels (mild, moderate, severe) based on user input.
